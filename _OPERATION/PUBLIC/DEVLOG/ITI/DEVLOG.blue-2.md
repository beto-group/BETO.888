#### I. Datacore Expansion & New Components

This cycle we shipped a full slate of brand-new components that expand what’s possible inside Obsidian and push us closer to building complete, integrated systems.

##### New Components

- **DATACORE QUERY BUILDER** – Interactive tool for building and testing Datacore queries in real-time with live results, context-aware suggestions, and a full-field inspector.
- **CHATBOT** – Minimal interface for sending messages to a Telegram bot through a serverless backend.
- **MOBILE MUSIC PLAYER** – Floating-action-button-powered PiP music player for mobile with background playback, search, queue, favorites, and advanced controls.
- **CARD PICKER** – Virtual 54-card deck simulator with persistent state, scoring system, and draw history.
- **RECEIPT TRACKER & DASHBOARD** – OCR + AI-powered receipt processing pipeline with a live financial analytics dashboard.
- **MULTI-PROVIDER AI CHAT** – Unified AI chat interface supporting multiple LLM providers, multimodal input, persistent history, and rich settings.
- **OCR READER** – Frontend for the Text Extractor plugin to run OCR on vault images with copy-to-clipboard output.
- **VIEWS CONTROL** – Meta-component that transforms any component into fullscreen, floating, PiP, or tabbed modes with a single click.

#### II. GitHub Repository Optimization

Introduced selective folder retrieval so you can pull only the exact components you want, reducing setup time and vault footprint.
