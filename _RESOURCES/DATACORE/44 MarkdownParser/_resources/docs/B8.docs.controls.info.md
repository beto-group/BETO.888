# MODULE 9 — IMMERSIVE CONTROL & INPUT MANAGEMENT

This module provides the advanced controls for creating focused, game-like, or modal experiences. The core pattern involves temporarily capturing and overriding Obsidian's default input handling, ensuring that user actions like keyboard presses and mouse movements are directed exclusively to the component, not to the wider application.

## Input Capture & Blocking

**INFO**

Controls for taking exclusive ownership of user input. This is the most critical pattern for creating immersive applications that need to prevent conflicts with Obsidian's native shortcuts and command palette.

**Use when**

You are building a game, a 3D world, a modal dialog, or any component where keys like `Cmd/Ctrl+W`, `WASD`, or `Space` must control your component, not Obsidian.

---

### Comprehensive Input Blocker

**Description**

This is the **recommended primary control** for any immersive experience. It's a robust pattern that manages focus on a component's container. When the component is focused, it automatically disables nearly all of Obsidian's commands and hotkeys by temporarily clearing the command registry. When blurred, it safely restores them. This is often encapsulated in a reusable module like `preventDefaultInputs`.

**Code (Pattern from `preventDefaultInputs` module)**
```javascript
function useInputBlocker(viewRef) {
  useEffect(() => {
    const el = viewRef.current;
    if (!el || !dc.app?.commands) return;

    let originals = {};
    const handleFocus = () => {
      // 1. Store original commands and functions
      originals.commands = dc.app.commands.commands;
      originals.execute = dc.app.commands.executeCommandById;
      
      // 2. Override with a blocking implementation
      dc.app.commands.commands = {}; // Clear command registry
      dc.app.commands.executeCommandById = id => {
        // Allow a specific command like closing the workspace to pass through
        if (id === 'workspace:close') originals.execute(id);
        return false; // Block everything else
      };
    };
    const handleBlur = () => {
      // 3. Restore originals
      if (originals.commands) dc.app.commands.commands = originals.commands;
      if (originals.execute) dc.app.commands.executeCommandById = originals.execute;
    };

    el.addEventListener('focus', handleFocus);
    el.addEventListener('blur', handleBlur);
    return () => {
      el.removeEventListener('focus', handleFocus);
      el.removeEventListener('blur', handleBlur);
      handleBlur(); // Ensure restoration on unmount
    };
  }, [viewRef]);
}
```

### Pointer Lock

**Description**

The browser API for capturing all mouse movement, hiding the cursor, and providing delta values (`movementX`, `movementY`). This is essential for first-person camera controls in 3D scenes and is typically used in conjunction with the input blocker.

**Code (Pattern from `GameEngineBuild`)**
```jsx
const canvasRef = useRef(null);

useEffect(() => {
  const canvas = canvasRef.current;
  if (!canvas) return;

  // 1. Request pointer lock on click
  const lockPointer = () => canvas.requestPointerLock();
  canvas.addEventListener('click', lockPointer);

  // 2. Listen for mouse movement while locked
  const handleMouseMove = (e) => {
    if (document.pointerLockElement === canvas) {
      // Use e.movementX and e.movementY to rotate a 3D camera
    }
  };
  document.addEventListener('mousemove', handleMouseMove);

  // 3. Cleanup listeners and exit lock on unmount
  return () => {
    canvas.removeEventListener('click', lockPointer);
    document.removeEventListener('mousemove', handleMouseMove);
    if (document.pointerLockElement === canvas) document.exitPointerLock();
  };
}, []);

// return <canvas ref={canvasRef} />;
```

## Scoped Input Handling

**INFO**

Controls for listening to keyboard events in a way that respects the application's state and component focus, preventing global conflicts.

---

### Component-Level Key Listeners

**Description**

Attaching `keydown` and `keyup` listeners directly to your component's container. This ensures the events are only captured when the component (or an element inside it) has focus.

**Use when**

You need to handle simple, localized keyboard actions (like navigating a list with arrow keys) without blocking all other Obsidian hotkeys.

**Code**
```jsx
const containerRef = useRef(null);

useEffect(() => {
  const el = containerRef.current;
  if (!el) return;

  const handleKeyDown = (e) => {
    if (['ArrowUp', 'ArrowDown'].includes(e.key)) {
      e.preventDefault(); // Prevent page scrolling
      console.log(`Key pressed inside component: ${e.key}`);
    }
  };
  
  el.addEventListener('keydown', handleKeyDown);
  return () => el.removeEventListener('keydown', handleKeyDown);
}, []);

// return <div ref={containerRef} tabIndex={0}>...</div>;
```

### Global Keybinds with Context

**Description**

A more advanced and powerful pattern for managing a complex set of keyboard shortcuts for an entire application. A global `keydown` listener is attached, but it checks conditions (like whether an input field is focused) before executing an action. This provides the power of global shortcuts while respecting user context.

**Code (Pattern from `ObsidianActions` / `N8NLookAlike`)**
```javascript
// A custom hook to manage global keybinds
function useKeybinds({ bindings }) {
  useEffect(() => {
    const handleKeyDown = (e) => {
      // Helper to check if the user is typing in an input, textarea, etc.
      const isEditableTarget = (event) => {
        return event.target.isContentEditable || ['INPUT', 'TEXTAREA', 'SELECT'].includes(event.target.tagName);
      };

      // 1. Ignore keybinds if the user is typing text.
      if (isEditableTarget(e)) return;

      // 2. Construct the key combination string (e.g., "Ctrl+k", "delete").
      const keyString = /* ... logic to build key string from e.key, e.ctrlKey, etc. ... */;
      
      // 3. If the pressed key matches a defined binding, execute its function.
      if (bindings[keyString]) {
        e.preventDefault();
        e.stopPropagation();
        bindings[keyString](e);
      }
    };
    
    document.addEventListener('keydown', handleKeyDown);
    return () => document.removeEventListener('keydown', handleKeyDown);
  }, [bindings]); // Re-bind if the bindings object changes
}

// Example Usage in a component:
const bindings = useMemo(() => ({
  "Ctrl+k": () => console.log("Search action!"),
  "delete": () => console.log("Delete action!"),
  "g": () => console.log("Toggle grid snap!"),
}), []);
useKeybinds({ bindings });
```

### Obsidian Actions

**Description**

A set of pre-built utility functions that perform common Obsidian interactions. These are often used as the actions triggered by the global keybinds pattern.

**Code (Pattern from `ObsidianActions` / `N8NLookAlike`)**
```javascript
const ObsidianActions = {
  // Opens a file in a new tab, respecting whether it should be in the foreground or background.
  openFile: async (path, openMode = 'tab-fg') => {
    let newLeaf = true;
    const openState = { active: true };

    switch (openMode) {
      case 'current': newLeaf = false; break;
      case 'split': newLeaf = 'split'; break;
      case 'window': newLeaf = 'window'; break;
      case 'tab-bg': newLeaf = true; openState.active = false; break;
    }
    await dc.app.workspace.openLinkText(String(path), '', newLeaf, openState);
  },

  // Executes a command from the Obsidian command palette by its ID.
  runCommand: async (commandId) => {
    await dc.app.commands.executeCommandById(commandId);
  },
  
  // Displays a transient notification message at the top of the screen.
  showNotice: (message, timeout = 3000) => {
    new Notice(message, timeout);
  }
};
```
