## Data Display Controls

**What it is**

Controls for rendering structured data (typically from dc.useQuery) into dynamic, feature-rich tables and lists.

**Use when**

You need to display query results in a tabular format, handle thousands of rows smoothly, or implement features like column reordering, pagination, and grouping.

### <DataTable>

A pre-built, high-performance component for virtualized tables. Ideal for quickly displaying large datasets with minimal boilerplate.

codeJsx

```
// --- In a ViewComponent ---
const { useState } = dc;

function MyDataTable({ rows }) {
  const columns = [
    { key: "name", title: "File Name", width: 300, editable: true },
    { key: "status", title: "Status", width: 150 },
    { 
      key: "created", 
      title: "Date Created",
      render: (row) => row.$ctime.toFormat("yyyy-MM-dd"),
    },
  ];

  const handleEdit = (row, patch) => {
    // Logic to save the change, e.g., update frontmatter
    console.log(`Updating ${row.$path} with`, patch);
  };

  return <dc.DataTable rows={rows} columns={columns} virtualization onEdit={handleEdit} />;
}
```

### Custom Table

Building a table from scratch using standard elements and Datacore state management. This offers maximum flexibility for custom features like dynamic columns and grouping.

codeJsx

```
// --- In a ViewComponent ---
const { useState } = dc;

// This is a simplified version of the Dynamic Datacore View pattern
function MyCustomTable({ rows, columns }) {
  const STYLES = {
    row: { display: 'flex', borderBottom: '1px solid #333' },
    cell: { flex: '1 0 150px', padding: '8px', overflow: 'hidden' },
  };

  return (
    <div>
      <div style={STYLES.row}>
        {columns.map(col => <div style={STYLES.cell} key={col.key}><strong>{col.title}</strong></div>)}
      </div>
      {rows.map(row => (
        <div style={STYLES.row} key={row.$path}>
          {columns.map(col => <div style={STYLES.cell} key={col.key}>{row[col.key]}</div>)}
        </div>
      ))}
    </div>
  );
}
```

### Pagination Controls

Client-side logic for breaking a large dataset into manageable pages.

codeJsx

```
// --- In a ViewComponent with a large 'data' array ---
const { useState, useMemo } = dc;
const ITEMS_PER_PAGE = 50;

function PaginatedList({ data }) {
  const [currentPage, setCurrentPage] = useState(1);
  const totalPages = Math.ceil(data.length / ITEMS_PER_PAGE);

  const paginatedData = useMemo(() => {
    const start = (currentPage - 1) * ITEMS_PER_PAGE;
    return data.slice(start, start + ITEMS_PER_PAGE);
  }, [data, currentPage]);
  
  return (
    <div>
      {/* Render your paginatedData here */}
      <div>
        <button onClick={() => setCurrentPage(p => Math.max(1, p - 1))} disabled={currentPage === 1}>Prev</button>
        <span> Page {currentPage} of {totalPages} </span>
        <button onClick={() => setCurrentPage(p => Math.min(totalPages, p + 1))} disabled={currentPage === totalPages}>Next</button>
      </div>
    </div>
  );
}
```

## Drag & Drop Controls

**What it is**

Controls for making UI elements physically movable to trigger actions or reorder data.

**Use when**

You need to implement reordering, Kanban-style boards, or allow users to drag data out of your component into an Obsidian note.

### Draggable Item

Makes a component draggable using the native HTML5 draggable attribute. The onDragStart handler attaches the necessary data for the drop target to consume.

codeJsx

```
// --- Inside a component rendering a list of items ---
function DraggableCard({ item, onDragStart }) {
  // The 'itemId' is what identifies the data being moved.
  const handleDragStart = (e) => {
    e.dataTransfer.setData("text/plain", item.id);
    e.dataTransfer.effectAllowed = "move";
    onDragStart(item.id); // Optional: notify parent of drag start
  };

  return (
    <div draggable onDragStart={handleDragStart}>
      {item.content}
    </div>
  );
}
```

### Drop Target

Defines an area that can accept a drop. The onDrop handler reads the data from the event and performs an action. onDragOver must call preventDefault to allow the drop.

codeJsx

```
// --- Inside a component like a Kanban column ---
function KanbanColumn({ columnId, onDropItem }) {
  const handleDrop = (e) => {
    e.preventDefault();
    const itemId = e.dataTransfer.getData("text/plain");
    onDropItem(itemId, columnId); // Notify parent of the drop event
  };

  const handleDragOver = (e) => {
    e.preventDefault(); // This is crucial to allow dropping
    e.dataTransfer.dropEffect = "move";
  };

  return (
    <div onDrop={handleDrop} onDragOver={handleDragOver}>
      {/* Render cards here */}
    </div>
  );
}
```

### Drag-out to Obsidian

A specialized drag pattern where the data set in onDragStart is a formatted wikilink or tag, allowing the user to drag an item from your component directly into an Obsidian note.

codeJsx

```
// --- Inside a component rendering a list of notes or tags ---
function DraggableWikiLink({ note }) {
  const handleDragStart = (e) => {
    // Set the data to a format Obsidian understands.
    const linkText = `[[${note.$path}]]`;
    e.dataTransfer.setData("text/plain", linkText);
    e.dataTransfer.effectAllowed = "copy";
  };

  return (
    <a href="#" draggable onDragStart={handleDragStart}>
      {note.$name}
    </a>
  );
}
```

## Navigation Controls

**What it is**

Controls for building UIs that navigate through nested or hierarchical data structures.

**Use when**

You are building a file explorer, a nested tag browser, or any UI where users can "drill down" into deeper levels of data.

### Hierarchical State

Managing the navigation path using a state array. Each element in the array represents a level in the hierarchy.

codeJsx

```
// --- In a component like a Tag Browser ---
const { useState } = dc;

function TagBrowser() {
  const [currentPath, setCurrentPath] = useState([]); // e.g., ['projects', 'active']

  // To navigate deeper:
  const drillDown = (nextLevel) => {
    setCurrentPath(prev => [...prev, nextLevel]);
  };

  // To go back up one level:
  const goBack = () => {
    setCurrentPath(prev => prev.slice(0, -1));
  };
  
  // Render content based on the currentPath...
  return <div>{/* UI elements call drillDown and goBack */}</div>;
}
```

### Breadcrumbs

A UI element that visually represents the currentPath state, allowing the user to jump to any parent level in the hierarchy.

codeJsx

```
// --- Inside a component managing a 'currentPath' state array ---
function Breadcrumbs({ path, onNavigate }) {
  return (
    <div>
      <button onClick={() => onNavigate([])}>Home</button>
      {path.map((segment, index) => (
        <span key={index}>
          {' / '}
          <button onClick={() => onNavigate(path.slice(0, index + 1))}>
            {segment}
          </button>
        </span>
      ))}
    </div>
  );
}
```

## Ship It: Minimal Starter Flow

1. Use dc.useQuery to fetch a list of items for a table. Render them using the **Custom Table** pattern.
    
2. Make each row draggable using the **Draggable Item** pattern.
    
3. To allow reordering, make the list container a **Drop Target**.
    
4. If the items represent notes, implement **Drag-out to Obsidian** to let users create wikilinks easily.
    
5. If your data is nested (like tags a/b/c), manage the view with **Hierarchical State** and display **Breadcrumbs**.
