# Module 4 — Windowing & Display Management: Catalog & Applications (Final Draft)

This module provides the foundational patterns for controlling how and where components are rendered on the screen. It moves beyond simple inline views, enabling developers to create immersive, multi-window, and context-aware application experiences.

---

## Controls Catalog (Outline)

- **Display Mode Management**
    
    - <ScreenModeHelper>: A controller for toggling display modes.
        
    - helperRef.toggleMode(): Programmatically changing the display mode.
        
- **Dynamic Window Spawning**
    
    - <FreshPip>: A component for hosting content in a floating window.
        
    - spawnCustomPiP(): A function to dynamically create and render a <FreshPip> window with any component.
        
- **Window State & Persistence**
    
    - Z-Index Management: Bringing windows to the front on interaction.
        
    - Note: Positional persistence is a planned feature, currently handled by individual component logic.

## Display Mode Management

**What it is**

Controls that allow a single component instance to dynamically change its own container and presentation style, transitioning between different display modes like default, fullTab, and window.

**Use when**

You need to offer an "immersive" or "focus" mode for a component, such as a 3D world, a distraction-free editor, or an expanded dashboard.

### <ScreenModeHelper>

A controller component that provides the logic and (optionally) UI buttons for switching modes. It handles the complex DOM manipulation of detaching and re-parenting the component's container.

codeJsx

```
// --- In a ViewComponent ---
const { useRef } = dc;

function MyImmersiveComponent() {
  const containerRef = useRef(null);
  const helperRef = useRef(null); // To access the helper's API

  // Styles defining the component's appearance in each mode
  const defaultStyle = "position: relative; height: 400px; border: 1px solid #ccc;";
  const windowStyle = "position: fixed; top: 0; left: 0; width: 100vw; height: 100vh; z-index: 9999;";

  return (
    <div ref={containerRef}>
      {/* The component's main content goes here */}
      <ScreenModeHelper
        helperRef={helperRef}
        containerRef={containerRef}
        defaultStyle={defaultStyle}
        stylesByMode={{ window: windowStyle }}
        allowedScreenModes={["window"]}
      />
    </div>
  );
}
```

### helperRef.toggleMode()

An imperative function exposed by the <ScreenModeHelper> to programmatically trigger a mode change. This is useful for event-driven mode changes, like a button click within your component's UI.

codeJsx

```
// --- Inside MyImmersiveComponent ---

function MyImmersiveComponent() {
  // ... (setup from previous example)

  // A custom button inside your UI that triggers a mode change
  const handleEnterFocusMode = () => {
    if (helperRef.current) {
      helperRef.current.toggleMode('window');
    }
  };

  return (
    <div ref={containerRef}>
      <button onClick={handleEnterFocusMode}>Enter Focus Mode</button>
      {/* ... rest of your component and ScreenModeHelper */}
    </div>
  );
}
```

## Dynamic Window Spawning

**What it is**

Controls for creating new, fully independent floating windows at runtime. Unlike the multi-mode system, this pattern spawns a completely new instance of any specified component inside a draggable, resizable window.

**Use when**

You need to create "in-app" pop-up windows, tool palettes, or secondary displays, enabling a true multi-window application experience.

### spawnCustomPiP()

The core function (exposed via ScreenModeHelper's helperRef) that initiates the creation of a new window. It uses dc.require internally to load the target component's code and renders it into a <FreshPip> container.

codeJsx

```
// --- In a component that needs to spawn another component ---

async function openMusicPlayer() {
  // Assume a ScreenModeHelper is rendered somewhere to provide the helperRef.
  if (screenHelperRef.current) {
    screenHelperRef.current.spawnCustomPiP(
      "_RESOURCES/DATACORE/36 MusicPlayer/D.q.musicplayer.component.md",
      "ViewComponent",
      "MusicPlayer",
      { // Optional: custom styling for the window
        width: "380px",
        height: "600px",
        top: "100px",
        left: "100px",
      }
    );
  }
}
```

### <FreshPip>

The internal component that provides the window "chrome" (frame, close button) and hosts the dynamically loaded component. It is not typically used directly but is rendered by spawnCustomPiP. Its implementation includes logic for dragging, resizing, and z-index management.

codeJsx

```
// This component is used internally by spawnCustomPiP.
// You do not need to write this code, but it's useful for understanding.

function FreshPip({ onClose, component: LoadedComponent, customStyle }) {
  const containerRef = useRef(null);
  
  // Logic for dragging, resizing, and bringing to front goes here...
  
  return (
    <div ref={containerRef} className="fresh-pip" style={customStyle}>
      <button onClick={onClose}>X</button>
      {LoadedComponent ? <LoadedComponent /> : <div>Loading...</div>}
    </div>
  );
}
```

## Window State & Persistence

**What it is**

Controls and patterns for managing the state of floating windows, such as their stacking order.

**Use when**

You have multiple floating windows and need to ensure that the most recently interacted-with window appears on top.

### Z-Index Management

A global system that tracks the highest z-index among all active <FreshPip> windows. A pointerdown event on a pip's container brings it to the front by assigning it a new, higher z-index.

codeJsx

```
// This logic is built into the FreshPip component.
// No extra code is needed to enable it.

function bringToFront(container) {
  // 1. Find the highest z-index among all '.fresh-pip' elements.
  let highestZIndex = 10000;
  document.querySelectorAll('.fresh-pip').forEach(el => {
    const z = parseInt(window.getComputedStyle(el).zIndex, 10) || 0;
    if (z > highestZIndex) highestZIndex = z;
  });

  // 2. Assign a new, higher z-index to the target container.
  container.style.zIndex = highestZIndex + 1;
}

// A listener on the FreshPip container triggers this function.
// container.addEventListener("pointerdown", () => bringToFront(container));
```

## Ship It: Minimal Starter Flow

1. To make a component "poppable", wrap its content in a div with a ref (containerRef).
    
2. Add the **<ScreenModeHelper>** component inside this container, passing the containerRef and defining styles for the different modes.
    
3. To spawn a floating window from any component, ensure a <ScreenModeHelper> is rendered somewhere in your view to get access to its helperRef.
    
4. Call **helperRef.current.spawnCustomPiP(...)** with the path to the target component's file, its header, and the function name to render.
    
5. **Z-Index management** is handled automatically by the spawned <FreshPip> windows.
