# Project Preferred Styles

This document tracks the visual preferences and technical "winners" from the **Design Forge** sessions. These rules are mandatory for all future AI-generated UI components.

## 🏛️ Winning Aesthetics

### 1. Cyberpunk-Refined (Active Standard)
- **OKLCH Core**: `oklch(0.7 0.25 320)` (Vivid Purple/Magenta)
- **Neutrals**: Tinted darks (e.g., `#050508`)
- **Interaction**: Brisk 0.2s ease-out-expo transitions.
- **DNA**: Asymmetric clip-paths and monospace typography for metrics.

## 🚫 Avoidance List (AI Slop)
- **Generic AI Gradients**: Blue-to-purple linear gradients.
- **Safe Cards**: Perfectly centered, identical-width cards with heavy drop shadows.
- **Inter/System Defaults**: Avoid using Inter for display headings.
